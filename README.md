# 德州扑克练习 · Texas Hold'em Trainer

一个**纯前端、单机、可离线运行**的无限注德州扑克（No-Limit Texas Hold'em）现金局练习游戏。你与多个性格各异、可被长期观察的 AI 对手同桌对战，并配有实时胜率、决策复盘、手牌回放等学习辅助面板。

- 技术栈：**React + TypeScript (strict) + Vite + Zustand + Tailwind CSS**
- 零后端、零部署，刷新不丢数据（localStorage 持久化）
- 核心算法（牌型评估、边池分配、蒙特卡洛、赔率）均配 **Vitest 单元测试**

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器 (默认 http://localhost:5173)
npm run dev:host # 开发服务器并暴露局域网地址 (供 iPad/手机访问)
npm run build    # 生产构建 (输出到 dist/，可直接静态托管或本地打开)
npm run preview  # 预览生产构建 (已开启 --host)
npm run lan      # 构建 + 启动局域网联机服务器 (多人 + 人机同桌)
npm run server   # 仅启动联机服务器 (需已 build)
npm test         # 运行全部单元测试
npm run test:watch   # 监听模式
npm run typecheck    # 仅类型检查
```

> 构建产物为纯静态资源（`base: './'`），可直接双击 `dist/index.html` 离线运行。

## 局域网联机（多人 + 人机同桌）

支持**若干真人 + 若干人机**在同一局域网内同桌对战，无需互联网。架构为「权威服务器」：一台机器作为房主运行 Node 服务器，复用纯逻辑的 `engine/` 与 `ai/` 模块作为唯一裁判，向每个客户端**只下发本人可见的状态**（自己的底牌 + 公共信息，牌堆与他人底牌一律不下发），从根本上避免作弊。

### 开一桌

```bash
# 房主电脑（一条命令搞定，HTTP 与 WebSocket 同端口 8080）
npm run lan          # = npm run build && npm run server
```

启动后终端会打印局域网地址，例如 `http://192.168.1.23:8080`。

1. 房主与其他玩家用浏览器打开该地址（同一 Wi-Fi）。
2. 进入首页点 **「🌐 局域网联机」** → 输入昵称 → 加入。
3. 在**大厅**中各自点空座「坐下」；房主可「+ AI」把空位填成人机、设置盲注/起始码/难度，然后「开始游戏」。
4. 对局中每位真人有 30 秒行动倒计时（超时自动过牌/弃牌）；人机按性格自动行动。
5. **每手结束后暂停**，展示结果与各家盈亏；需**所有在座真人玩家都点「下一手」**才开始下一局（掉线/已离座者不计；设有 120 秒安全兜底，避免有人挂机导致永久卡住）。纯人机桌则短暂停顿后自动继续。

### 特性

- **真人 + 人机混合**：空座可由房主一键填充 AI（复用单机的性格 / 动态诈唬 / 难度系统）。
- **断线重连**：意外断开会在下一手坐出，重连后（同浏览器，凭 token）自动回到原座位继续。若有人掉线后房主选择「返回大厅」，其空位会被自动释放（可重新加入或填入 AI），不会因"幽灵座位"卡住而无法开始下一局。
- **输光可补码继续**：联机中输光筹码不会掉线或被踢回大厅——会显示「补码继续」按钮，点击即以满码回到牌桌（累计盈亏照常统计，不计补码为盈利）。补码后可正常点「下一手」继续（界面以服务器权威的座位筹码判断状态，补码后即时生效，不会卡住）。人数不足时牌桌暂停等待补码，而非结束。服务器对所有消息做了异常保护，单次操作出错也不会断开连接。
- **防作弊**：服务器按玩家视角裁剪状态，牌堆与他人手牌永不下发。
- **复用 UI**：联机牌桌复用单机的牌桌、下注交互与「数学参考」面板。
- **逐局确认**：每手结束暂停，所有在座真人「下一手」后才开新局，节奏由玩家掌控。
- 也可在开发模式联机：先 `npm run server`（房主），其他人 `npm run dev:host` 打开 5173 后在「局域网联机」里手动填 `ws://<房主IP>:8080/ws`。

> 实现：`server/`（HTTP 静态服务 + WebSocket 房间状态机），`src/online/`（协议与状态裁剪），`src/ui/online/`（连接 / 大厅 / 联机牌桌）。可用 `npm run typecheck:server` 校验服务器类型。

## 在 iPad / 平板上运行

本项目是纯静态、可离线的 PWA（渐进式 Web 应用），在 iPad 上有三种方式：

### 方式一：部署到静态托管后用 Safari 打开（最省心，推荐）

```bash
npm install && npm run build   # 产物在 dist/
```

把 `dist/` 目录上传到任意静态托管（Netlify 拖拽上传、GitHub Pages、Vercel、Cloudflare Pages 等），在 iPad 的 **Safari** 打开该网址。然后点 **分享 → 添加到主屏幕**，即可像原生 App 一样全屏、离线运行（已内置 Service Worker 预缓存，首次联网打开后即可断网使用）。

### 方式二：同局域网下连电脑的开发/预览服务器（无需部署）

在与 iPad 同一 Wi-Fi 的电脑上运行：

```bash
npm run dev:host        # 或先 npm run build 再 npm run preview
```

终端会显示形如 `http://192.168.x.x:5173/` 的 **Network** 地址，在 iPad Safari 输入该地址即可。同样可"添加到主屏幕"。

### 方式三：用 Capacitor 打包成原生 App，真正离线（如飞机上）

本仓库已内置 Capacitor 配置（`capacitor.config.ts`，`webDir` 指向 `dist`）。原生 App 会把全部网页资源打包进安装包，**完全不依赖网络**，装好后即使飞行模式也能玩。构建 iOS App **必须在 Mac 上用 Xcode**。

**前置条件**：一台 Mac、[Xcode](https://apps.apple.com/app/xcode/id497799835)（App Store 安装）、一个 Apple ID（免费即可，免费签名的 App 有效期 7 天，到期重连 Mac 再运行一次即可；付费开发者账号有效期 1 年）、一根数据线。

**步骤**：

```bash
# 1) 在 Mac 上获取代码并安装依赖
git clone <本仓库地址> && cd TexasPoker
npm install

# 2) 构建网页产物并生成 iOS 原生工程（首次）
npm run cap:add:ios      # = npm run build && npx cap add ios

# 3) 同步资源并打开 Xcode
npm run ipad             # = build + cap sync ios + cap open ios
```

随后在 **Xcode** 里：

1. 左侧选中 **App** 项目 → **Signing & Capabilities** 选项卡。
2. **Team** 选择你的 Apple ID（没有就点 *Add an Account* 登录）；把 **Bundle Identifier** 改成全局唯一的名字，如 `com.你的名字.texaspoker`。
3. 用数据线把 **iPad 连到 Mac**，在 iPad 上点"信任此电脑"。
4. Xcode 顶部的运行目标选择你的 **iPad**（不是模拟器），点 **▶ 运行**。App 会被安装到 iPad。
5. 首次运行 iPad 会拦截：到 iPad **设置 → 通用 → VPN 与设备管理 → 开发者 App**，点信任你的 Apple ID 证书。
6. 回到主屏幕打开 App —— 之后**断网/飞行模式都能离线运行**。
7. 以后更新内容：改完代码 `npm run ipad`，在 Xcode 再 ▶ 运行一次即可。

> 说明：`ios/` 原生工程是按机器生成的（含 CocoaPods 等），已在 `.gitignore` 中忽略，不随仓库提交——在你的 Mac 上首次 `npm run cap:add:ios` 时自动生成。

### 哪种最适合"飞机上离线玩"？

- **没有 Mac / 想最快**：用**方式一或二**——只要在有网时用 Safari 打开一次并"添加到主屏幕"，PWA 会把资源缓存到本地，之后断网（飞机上）照常运行。这是最简单直接的离线方案，无需任何编译。
- **想要装进去、彻底不依赖任何服务器**：用**方式三**做成原生 App，从安装那一刻起就完全离线。

> 提示：界面已做响应式布局，iPad 横屏为左右双栏（牌桌 + 侧边面板），竖屏自动堆叠；下注滑块、快捷按钮、全下二次确认等均支持触控。

## 玩法概览

1. 在开始界面选择**同桌人数 (2~9)**、**大盲级别 (0.5 / 1 / 2 / 5)**、**起始筹码 (BB)**、**难度**。
2. 点击「开始游戏」生成牌桌。每个对手在本桌生命周期内性格固定，可被你观察归纳；**换桌**才会重新生成对手。
3. 轮到你行动时使用底部操作栏：弃牌 / 过牌·跟注 / 加注（滑块 + 1/2 池、3/4 池、底池、全下等快捷按钮 + 键盘快捷键 `F/C/R/A`、`↑↓` 微调）。全下需二次确认防误触。
4. 每手结束后**不会自动跳转**，而是停在最终局面（公共牌、摊牌结果保留），并在侧边「🧠 本手复盘」中给出**逐步骤概率分析**与**每次操作是否合理**的评价；查看完毕点「下一手 →」继续。输光筹码可「补码」。
   - 若你**翻前就弃牌**：本手剩余的 AI 行动会被**快速跑完**（不必等待），随后仍**停在最终局面**并展示「🃏 弃牌牌面分析」——你弃掉的牌、跑完的公共牌，以及"本可获胜 / 弃牌正确（也会输）/ 本可打平"的结论，看完点「下一手」继续。
5. 由于可**补码（rebuy）**，当前筹码不反映胜负历史；每个座位会在筹码下方显示该玩家**本桌累计盈亏**（不含补码，绿涨红跌），联机模式同样显示（牌桌座位 + 侧边座位列表）。

## 学习辅助（练习核心）

- **数学参考面板**（默认隐藏，点「参考」展开）：实时胜率、补牌 outs、转牌/河牌命中率、底池赔率、跟注 EV、当前最佳成牌提示。
- **本手复盘（每手结束自动展示）**：手牌结束后停在最终局面，逐一列出你在翻前/翻牌/转牌/河牌的每个决策点：当时胜率、**底池赔率**、弃/跟/加三选项的 EV 对比、你的实际选择，并给出「合理 / 可改进 / 失误」的评价与文字点评。每个决策点可展开「计算公式」，显示胜率（蒙特卡洛模拟局数与假设范围）、底池赔率 `跟注 ÷ (底池 + 跟注)` 与跟注 EV 的具体代入过程。还会显示**本次投入占筹码比例**，并在「薄边 + 大额投入」时给出**资金管理/风险破产**提示（只看 EV 不够：薄边重注方差大，几次失利即难翻身）。
- **更真实的胜率估计**：胜率不再假设对手持「随机两张」，而是按**当前牌面下最强的前 X% 手牌**为对手建模（面对下注、越大的注、越靠后的街道范围越紧）。这修正了翻牌/河牌「跟注胜率虚高、实战却常输」的问题——对手在池中、尤其下注时的范围远强于随机。
- **考虑对手诈唬（极化范围）**：面对下注时，对手范围按**极化**建模——价值强牌 + 一定比例诈唬（弱牌/破产听牌）。因此你的中等牌（抓诈牌）会得到真实胜率（能赢下那部分诈唬），不再出现「对手河牌诈唬你、系统却显示 0% 胜率」的情况。诈唬比例随牌面湿润度上升、随对手人数（多人池）下降。
- **决策复盘（历史回放）**：在「手牌历史」中打开任意一手回放，逐步骤查看，并对比每个关键决策点的 EV（弃 / 跟 / 加）。
- **手牌历史与回放**：保存最近手牌，支持逐步回放与公共牌渐显。
- **对手行为 HUD**（默认关闭）：开启后在座位旁显示对手 VPIP/PFR/AGG 统计。界面明确提示——开启会降低你亲自观察对手风格的乐趣，是否使用由你决定。
- **📖 教学文档**：游戏页顶部「文档」按钮（开始界面也有入口）打开内置德州扑克教学，含基本规则、位置与起手牌、新手常用技巧、常见牌局分析、进阶技巧（范围思维/极化/尺度/阻断牌/GTO 与剥削/EV 与隐含赔率等），原理与实操并重。

## 三档 AI 难度

| 难度 | 性格分布 | 诈唬 | 位置意识 | 针对你 |
| --- | --- | --- | --- | --- |
| 简单 | 极端易读（岩石/跟注站/疯子） | 很少 | 无 | 否 |
| 中等 | 均衡可信（分布收紧，无明显过度诈唬者） | 受控、可信、不易被读 | 有 | 否 |
| 困难 | 混合策略 | 动态 | 强 | **读取你的行为画像反过来针对你** |

困难难度会根据持久化的「玩家行为画像」（你的弃牌倾向、诈唬频率、激进度等）调整：你爱弃牌→多偷你盲注；你爱摊牌看牌→减少诈唬转为价值下注。

**决策模型（更拟人、考虑底池赔率）**：
- **翻前按"范围"思考**：用 169 手起手牌强度百分位与各自的 VPIP/PFR 范围决策，范围随位置放宽/收紧，并按价格调整——下注越小（赔率越好）跟得越宽，面对大加注越紧（不再用对随机牌的胜率硬阈值，避免过紧/机械）。
- **翻后用胜率 × 底池赔率**：跟注/弃牌不是硬切线，而是围绕盈亏平衡点的**平滑概率**（sigmoid），并对听牌计入隐含赔率、对位置与性格（跟注倾向/激进度）做修正；面对极小注（赔率极好）几乎不弃。
- **混合策略减少规则化**：含慢打强牌、半诈唬、薄价值加注、偶发诈唬加注，以及阈值噪声，使同一局面不总是同一动作。
- **更克制、更拟人的尺度**：价值与诈唬**共用同一套下注尺度**（诈唬不再因尺寸异常而暴露）；**深筹码不会频繁全下**——只有在筹码相对底池很浅（低 SPR 的承诺点）或极强牌时才会全下，普通下注/诈唬一律保留筹码而非推全下。
- **中等难度更统一、更难读**：中等对手的性格分布被收紧为稳健 TAG，且诈唬频率按难度封顶（中等更低），避免出现"个别 AI 频繁诈唬、一眼看穿"的情况——每个中等对手都是价值/诈唬较均衡的对手。

### 货币模型

为保证边池/分配全程整数运算精确，内部以**小盲为最小单位**：`SB = 1 chip`、`BB = 2 chips`、100 BB = 200 chips。所选大盲级别（0.5/1/2/5）仅作为展示用货币倍率；界面主要以 BB 显示。

## 关键算法设计说明

- **牌型评估器**：将一手 5 张牌编码为单个可比较整数 `category * 15^5 + tiebreakers`（base-15 保证 JS 双精度内精确），`O(1)` 比较；7 张牌中枚举出最佳类别并正确处理踢脚、轮子顺子（A-2-3-4-5）与平局。
- **边池分配器**：纯函数。按「最小非零下注档位」逐层剥离，弃牌者的死钱保留在池中但不参与争夺；分配时按 7 张最佳牌定胜负，平分后的奇数筹码从 button 左侧最近的合资格玩家开始逐枚发放。
- **蒙特卡洛**：移除已知牌后随机发对手手牌与公共牌跑若干局；`range` 模式用拒绝采样让对手偏向更强范围。可注入种子随机源以便复现测试。
- **下注规则**：完整实现最小加注校验、不足额 all-in **不重开**加注权（已行动者不再获得行动）、跟注/过牌/加注/全下、盲注轮转与翻前翻后行动顺序（含单挑特例）。

## 持久化

累计盈亏曲线、总手数 / 胜率 / BB·100 / 摊牌胜率、设置项、手牌历史、（困难难度用的）玩家行为画像，均存于 `localStorage`（键 `texas-poker-trainer:v1`），刷新不丢。可在「盈亏统计」中一键重置。
